# QA Artifacts

This directory contains browser-subagent artifacts (screenshots or short recordings of the flow) for UI packages, as required by the `AGENTS.md` protocol.

**Instructions for Antigravity lane:**
Since Antigravity is a headless agent, please generate local visual artifacts manually if a browser subagent plugin is not available:
1. Run `npm run dev`
2. Open the app in Chrome/Edge and set the viewport to 390px (iPhone 12/13/14).
3. Take screenshots of the completed UI flows (e.g. Wardrobe, Drop-offs, Stats).
4. Save them in this directory and reference them in your commits.
